# Lucky Draw — 課堂抽獎／抽學生

小提琴課堂用的單頁 PWA，純前端、離線可用、不需要任何後端或 Excel。

| 檔案 | 用途 |
|---|---|
| `index.html` | **抽獎轉盤** — 獎勵／處罰兩組項目，轉盤抽一項 |
| `pick.html` | **抽學生** — 班級名單隨機點名，抽過不重複 |
| `wheel.js` | 兩頁共用的轉盤繪製與落點計算 |
| `sw.js` | Service worker（離線快取） |
| `test/verify.js` | 回歸測試（需要 Playwright） |

資料全部存在瀏覽器的 localStorage，不會上傳：
`lucky-draw-data`（獎懲項目）、`lucky-draw-roster`（班級名單與本輪抽過的人）。

## 動手改之前必讀

### 1. 改了 `index.html` / `pick.html` / `wheel.js` → 一定要升 `sw.js` 的 `CACHE` 版號

`sw.js` 是 cache-first（`caches.match(req) || fetch(req)`），已安裝的 PWA 會**無限期**吃舊檔。
不升版號的話，改完在手機上看起來會像「根本沒修」。新增檔案也要加進 `ASSETS`。

### 2. 轉盤多轉的圈數必須是「整數圈」

`wheel.js` 的 `planSpin()` 把旋轉量拆成兩段：

```
totalSpin = 整數圈 × 2π  +  delta（往前轉到中獎格還差的角度，0~2π）
```

2026-11-01 修掉的 bug 就是圈數寫成 `(5 + Math.random()*3) * 2π`（小數圈）：
那個「零點幾圈」會被直接加到最終角度上，把算好的落點推掉一個隨機量，
結果**顯示框和底圖完全無關**（一致率退化成 1/n，6 項時只有 16.6%）。

同時修掉的還有 `targetAngle` 多加的 `+ π/2`（固定差四分之一圈）。

### 3. 轉動期間要鎖住會改變清單的控制項

`spin()` / `draw()` 在開頭就把當下的項目清單抓進閉包。如果轉到一半使用者切換模式、
換班級或改名單，底圖畫的是新清單、宣告的卻是舊清單 —— 又會對不上。
兩頁都在轉動期間把模式鈕／班級選單／設定鈕一起 `disabled`。

### 4. 轉盤的人數上限是 12（`pick.html` 的 `WHEEL_MAX`）

300px 的轉盤上，指針底部寬 32px。實測：

| 人數 | 每格角度 | 外緣一格寬 | 指針蓋住 |
|---|---|---|---|
| 10 | 36° | 88px | 0.36 格 |
| 20 | 18° | 44px | 0.73 格 |
| 30 | 12° | 29.3px | **1.09 格** |

**13 人以上指針就會蓋到超過半格，看不出它指著誰。** 名字本身其實到 30 人都還讀得到
（名字沿半徑寫，扇形窄不太影響），所以瓶頸是指針不是文字。
`pick.html` 因此在人數 > `WHEEL_MAX` 時改用「名字快閃定格」，任何班級人數都成立。

⛔ 判準是**全班總人數**（`useWheel()`），不是剩餘人數：呈現方式整輪固定，
人少的班就轉盤到底、人多的班就快閃到底。用剩餘人數的話，30 人班抽到剩 12 人時
介面會當場從快閃換成轉盤，上課中很突兀。

## 驗收

```bash
npm i -D playwright-core        # 或設環境變數 PLAYWRIGHT_PATH 指向別處裝好的版本
node test/verify.js
```

會檢查：

- **落點一致性** — 轉完後取**指針正下方那個像素的色號**反推停在哪一格，跟宣告的名字比對。
  ⛔ 不可以用 `planSpin` 的公式去驗 `planSpin` 的結果，那是循環論證。
- ⚠️ 產品的底色表只有 6 色，`n = 12` 時第 *i* 格和第 *i+6* 格的鄰色組完全相同 ⇒
  測試會**把調色盤換成互不相同的顏色**（只換顏色，幾何與角度計算不動）來消掉歧義。
- **快閃模式** — 畫面上定格的名字 vs 結果框宣告的名字。
- **名單解析** — 從 Excel 貼上的各種形狀（一欄、座號+姓名、CSV、`1.` `1、` 編號、姓名+備註）。
- **不重複** — 抽滿一輪不應出現重複的人。
- **轉動中干擾** — 中途點模式鈕／設定鈕不應造成不一致。
- **突變測試** — 故意把落點公式改錯，確認上面那把量尺真的會報錯（不是永遠通過的假指標）。

## 名單怎麼進來

不需要 Excel 檔。在 Excel／Google 試算表選一整欄 `Ctrl+C`，到設定視窗的文字框 `Ctrl+V` 即可；
座號會自動去掉。也可以匯入 `.txt` / `.csv`、或把名單匯出成 `.txt`。
